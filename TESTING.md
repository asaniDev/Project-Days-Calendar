# Testing

## 1. Unit Tests

Unit tests are written using Vitest in `common.test.mjs` to test the date-related helper functions in `common.mjs`.

To run the tests, use:

```bash
npm test
```

The tests cover:

- `getFirstDay()` – checks the correct weekday for the first day of a month.
- `getDaysInMonth()` – checks the number of days in a month, including February in leap and non-leap years.
- `getNumberOfWeeks()` – checks the number of weeks needed to display a month.
- `getWeekdays()` – checks the dates of specific weekdays within a month and ensures dates from the next month are not included.
- `formatDate()` – checks that dates are formatted as `YYYY-MM-DD`, including leading zeros for single-digit months and days.

**Result:** All 10 unit tests passed.

## 2. Manual Testing

The calendar was checked manually to verify that:

- The calendar displays the correct month and year.
- The week starts on Sunday.
- The Previous and Next buttons navigate between months.
- The month and year dropdowns display the selected month and year.
- Commemorative days appear on the correct dates.
- The calendar displays the correct dates for different months and years.
- The Previous and Next buttons continue working beyond the initial range of years in the dropdown.

## 3. iCalendar Testing

The iCalendar file was generated by running:

```bash
node generate-ical.mjs
```

The generated `days.ics` file was checked to verify that:

- It contains 55 commemorative day events covering 2020–2030 inclusive.
- Each event has an all-day start date using `DTSTART;VALUE=DATE`.
- The file contains 55 event entries and 55 all-day start dates.
- The event dates match the expected dates for the corresponding commemorative days.
- The file was successfully imported into Google Calendar.
- The imported events appeared on the correct dates.

**Result:** The iCalendar file was generated and imported successfully into Google Calendar.
